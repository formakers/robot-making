# AI 로봇 제작 마스터 클래스

> 기초 전기·전자부터 Arduino, Python, OpenCV, YOLO, ROS 2, MoveIt, LeRobot, 휴머노이드, 제품화와 창업까지 단계적으로 배우는 로봇 제작 학습 과정입니다.

---

## 과정 소개

로봇 제작은 단순히 모터를 연결하거나 프로그램을 작성하는 작업이 아닙니다.

로봇은 다음 기술이 하나의 시스템으로 연결되어 동작합니다.

```text
기계 설계
+ 전기·전자
+ 모터 제어
+ 센서
+ 프로그래밍
+ 영상처리
+ ROS 2
+ 인공지능
```

이 과정의 목표는 단순히 예제 코드를 실행하는 데 그치지 않고, 로봇의 구조를 이해하고 직접 설계·제작·제어하며 최종적으로 제품화할 수 있는 능력을 갖추는 것입니다.

# 1단계: 로봇의 기초 이해

로봇이 무엇이며 어떤 구조로 움직이는지 배웁니다.

로봇의 가장 기본적인 동작 구조는 다음과 같습니다.

```text
입력(Input)
    ↓
처리(Process)
    ↓
출력(Output)
```

센서가 정보를 받아들이고, 제어기와 소프트웨어가 처리한 뒤, 모터와 액추에이터가 실제 움직임을 만듭니다.

### 주요 학습 내용

- 로봇과 일반 기계의 차이
- 센서와 액추에이터
- 기계, 전기, 전자, 제어, 소프트웨어
- 입력, 처리, 출력의 흐름
- AI와 로봇의 차이
- 로봇 시스템의 전체 구조

---

- 전압
- 전류
- 저항
- 옴의 법칙
- 직류와 교류
- 배터리
- SMPS

- PWM
- 시리얼 통신

카메라, 센서, AI, MoveIt, 모터 제어 프로그램을 각각 실행하고 서로 데이터를 주고받도록 구성합니다.

# 12단계: URDF와 Xacro

URDF를 사용하여 실제 로봇의 구조를 컴퓨터 안에 정의합니다.

### URDF에 포함되는 정보

- 링크 이름
- 관절 이름
- 부모 링크와 자식 링크
- 관절 축
- 링크 크기와 형상
- 시각 모델
- 충돌 모델
- 질량
- 관성
- 관절 제한

Xacro는 반복되는 URDF 내용을 변수와 매크로로 관리할 수 있게 해줍니다.

---

# 13단계: MoveIt

MoveIt은 로봇팔의 자세와 이동 경로를 계산하는 소프트웨어입니다.

### 주요 기능

- 순기구학
- 역기구학
- 충돌 검사
- 경로 계획
- 관절 목표 이동
- 자세 목표 이동
- 궤적 생성
- Planning Scene
- 그리퍼 동작 연동

RViz에서 목표 자세를 지정하면 로봇팔이 충돌을 피하면서 이동할 경로를 계산합니다.

---

# 14단계: MoveIt Python API

Python 프로그램으로 MoveIt을 제어하여 로봇 동작을 자동화합니다.

```text
현재 관절값 읽기
       ↓
목표 위치 설정
       ↓
경로 계획
       ↓
로봇 이동
       ↓
그리퍼 열기 또는 닫기
```

### 응용 예제

- 홈 위치 이동
- 특정 관절만 이동
- 여러 위치 순차 이동
- 반복 작업
- 그리퍼 자동 제어
- 안전 범위 검사
- Pick & Place 동작 구성

---

# 15단계: Depth Camera

일반 RGB 카메라는 영상의 가로와 세로 좌표를 제공하지만 물체까지의 실제 거리를 바로 알기 어렵습니다.

Depth Camera를 사용하면 다음 정보를 얻을 수 있습니다.

```text
X 좌표
Y 좌표
Z 거리
```

### 주요 학습 내용

- RGB 영상
- Depth 영상
- 깊이값 읽기
- 카메라 내부 파라미터
- 픽셀 좌표를 3차원 좌표로 변환
- 카메라 좌표와 로봇 좌표 변환
- Hand-Eye Calibration

---

# 16단계: AI Pick & Place

YOLO, Depth Camera, ROS 2, MoveIt을 연결하여 물체를 자동으로 집고 옮기는 시스템을 만듭니다.

```text
카메라
   ↓
YOLO 객체 인식
   ↓
깊이 측정
   ↓
3차원 위치 계산
   ↓
로봇 좌표 변환
   ↓
MoveIt 경로 계획
   ↓
그리퍼로 물체 집기
   ↓
목표 위치에 놓기
```

이 단계는 앞에서 배운 기술을 하나의 실제 AI 로봇 시스템으로 통합하는 과정입니다.

---

# 17단계: LeRobot

사람이 직접 로봇을 조작한 시범 데이터를 수집하고 AI 모델을 학습합니다.

```text
사람의 시범 동작
       ↓
카메라 및 관절 데이터 기록
       ↓
데이터셋 생성
       ↓
AI 정책 학습
       ↓
로봇이 작업 재현
```

### 주요 학습 내용

- Leader와 Follower 로봇
- Teleoperation
- 데이터 수집
- 에피소드 구성
- 카메라와 관절 데이터 동기화
- 데이터셋 업로드
- 모델 학습
- 체크포인트
- Rollout
- 학습 결과 평가

---

```text
10단계 로봇팔 제작
```

로봇의 몸체를 설계하고 실제 부품을 조립하여 움직이는 로봇팔을 제작합니다.

## 4. ROS 2와 로봇팔 제어

```text
11단계 ROS 2
12단계 URDF와 Xacro
13단계 MoveIt
14단계 MoveIt Python API
```

실제 로봇과 가상 모델을 연결하고 충돌 없는 움직임과 자동 작업을 구현합니다.

## 5. AI 로봇 통합

```text
15단계 Depth Camera
16단계 AI Pick & Place
17단계 LeRobot
18단계 휴머노이드
```

로봇이 물체를 보고, 위치를 계산하고, 행동을 수행하며, 데이터로 작업을 학습하도록 만듭니다.

## 6. 제품과 사업

```text
19단계 제품화
20단계 창업 및 양산
```

개인 프로젝트를 안정적인 제품과 실제 로봇 사업으로 발전시킵니다.
