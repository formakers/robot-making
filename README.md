# Robot Making Master Class

## 로봇 제작 마스터 클래스

이 저장소는 초보자부터 전문가까지 로봇을 직접 만들기 위한 학습 자료를 정리한 프로젝트입니다.

### 학습 과정

1. 로봇의 기초 이해
2. 전기와 전자 기초
3. 아두이노 기초
4. 모터 제어
5. 센서
6. Python
7. OpenCV
8. YOLO
9. CAD
10. 로봇팔 제작
11. ROS2
12. URDF
13. MoveIt
14. MoveIt Python API
15. Depth Camera
16. AI Pick & Place
17. LeRobot
18. 휴머노이드
19. 제품화
20. 창업
